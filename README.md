# 📦 StockMaster - Sistema de Gestión de Inventarios

## 🚀 Descripción
StockMaster es una aplicación web completa para la gestión de inventarios, desarrollada con React, Node.js y PostgreSQL.

## 🏗️ Arquitectura
- **Frontend**: React.js
- **Backend**: Node.js + Express
- **Base de Datos**: PostgreSQL
- **Balanceador**: Nginx
- **Contenedores**: Docker
- **CI/CD**: GitHub Actions

## 📋 Prerrequisitos
- Docker & Docker Compose
- Node.js 18+
- PostgreSQL 15+
- Git
